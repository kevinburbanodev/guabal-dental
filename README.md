# Guabal Dental

Demo landing page for an invented dental clinic in Cali, Colombia. The page is a glazed tile wall: open appointments, treatments and questions are tiles. Built with Vue 3, TypeScript, Vite and Tailwind CSS v4.

The clinic, its team, prices and schedules are made up. The booking form sends nothing: it shows the message a real site would open in WhatsApp.

```bash
npm install
npm run dev
```

`npm run build` type-checks and builds. Photos from Unsplash, see [public/photos/CREDITS.md](public/photos/CREDITS.md). Fonts (Anybody, Onest) are self-hosted through Fontsource.
